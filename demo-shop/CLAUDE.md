# demo-shop

A small Node shop with planted bugs, used to try pinround. It is not part of pinround.

- The pinround build rules in `../CLAUDE.md` (phases, PHP, quality gates, hand-off notes) do not apply in this folder.
- Plain Node 20+, no packages: `npm start` serves http://localhost:8090, `npm test` runs the tests.
- Do not open `BUGS.md`: it holds the answers. Find the bugs from the person's pinround notes and the code.
