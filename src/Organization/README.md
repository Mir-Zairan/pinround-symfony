# Organization

Organizations, teams, members, roles, invitations and settings such as ping limits and AI policy. It owns the tables `org_organization`, `org_membership`, `org_team`, `org_team_member`, `org_invitation` and `org_settings`. Its Api is `MembershipQueries`, `TeamQueries` and `OrgSettings`. It may use the Api of Identity.

See the [module catalogue](../../docs/02-architecture/modules.md#organization-org_).
