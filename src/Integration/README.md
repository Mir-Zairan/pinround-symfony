# Integration

The Jira link: one-time import, status mapping, outbound sync and incoming webhooks. It owns the tables `int_jira_connection`, `int_project_link`, `int_status_mapping`, `int_external_ref` and `int_sync_log`. Its Api is `ExternalRefs`. It may use the Api of Ticketing and Workflow.

See the [module catalogue](../../docs/02-architecture/modules.md#integration-int_).
