# Web

The UI shell: layout, navigation built from the user's roles, Home composition and the design-system Twig components. It has no business logic and only puts other modules' UI pieces together. It owns one table, `web_home_focus` (each user's Home focus chip per organization), and has no Api of its own. It may use the Api of Insight, Organization, Notification, Ticketing and Workflow (read only). `UI\Controller\TeamController` serves the team page `GET /teams/{slug}` (`team_show`): 404 for a slug no team of the request's organization has, then `TEAM_VIEW`; it reads the team (`TeamQueries::bySlug`) and its projects (`ProjectQueries::projectsOf`, one query plus one batch of open ticket counts) and shows the projects, a People shell and, to anyone but the team's lead, "Only the team lead can change projects and steps." "See tickets" links to `ticketing_tickets?project=KEY` once that route exists (`UI\Team\ProjectTicketsLink`). For the lead it adds "Remove" on each project, and for the lead or an admin an "Add project" dialog (link projects that have no team, create a new one) that posts to the `Ticketing\UI\TeamProjectsController` routes; `assets/controllers/project-picker_controller.js` filters its list.
