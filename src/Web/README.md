# Web

The UI shell: layout, navigation built from the user's roles, Home composition and the design-system Twig components. It has no business logic and only puts other modules' UI pieces together. It owns one table, `web_home_focus` (each user's Home focus chip per organization), and has no Api of its own. It may use the Api of Insight, Organization, Notification, Ticketing and Workflow (read only). `UI\Controller\TeamController` serves the team page `GET /teams/{slug}` (`team_show`): 404 for a slug no team of the request's organization has, then `TEAM_VIEW`; it reads the team (`TeamQueries::bySlug`) and its projects (`ProjectQueries::projectsOf`, one query plus one batch of open ticket counts) and shows the projects, a People shell and a line under the title: for the lead "You lead this team. You link its projects and add its own steps.", for an admin who is not the lead "Only the team lead can remove projects and change steps.", for anyone else "Only the team lead can change projects and steps." "See tickets" links to `ticketing_tickets?project=KEY` once that route exists (`UI\Team\ProjectTicketsLink`). For the lead it adds "Remove" on each project, and for the lead or an admin an "Add project" dialog (link projects that have no team, create a new one) that posts to the `Ticketing\UI\TeamProjectsController` routes; `assets/controllers/project-picker_controller.js` filters its list. Below the projects it shows "How work moves here": the policy sentence (`SettingsQueries::stepPolicyOf`), the five groups with the team's steps (`StepQueries::moveTargetsFor`, so none of the team's own steps under `locked`), team steps highlighted with a `×` for whoever has `STEP_CHANGE_TEAM`, an "Add a team step" panel for the same people, and the three rules (`RuleQueries::rulesFor`) as switches for whoever has `RULES_CHANGE_TEAM`, else as On/Off marks "set by the team lead" under `team` and "set by the admin" otherwise; the forms post to the `Workflow\UI\TeamWorkflowController` routes, whose names, token ids and labels `TeamController::WORKFLOW_FORMS` copies.
